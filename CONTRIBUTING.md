# Contributing Guidelines

Thank you for your interest in this repository.

This repository primarily maintains a personal technical profile. Contributions are expected to focus on:

- fixing factual or formatting issues;
- improving documentation quality;
- suggesting improvements to profile presentation.

## Workflow

1. Open an issue or discussion before making substantial changes.
2. Submit changes through a pull request.
3. Keep changes focused and easy to review.

## Content principles

Please avoid adding:

- unsupported claims;
- exaggerated achievements;
- unrelated promotional content.

The goal is to maintain an accurate and professional technical profile.
