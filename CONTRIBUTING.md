# Contributing Guidelines

Thank you for your interest in this repository.

This repository primarily maintains a personal technical profile. Contributions
are expected to focus on:

- fixing factual or formatting issues;
- improving documentation quality;
- suggesting improvements to profile presentation;
- keeping public project/contribution information accurate and current.

## Workflow

1. Read [AGENTS.md](AGENTS.md) and [MAINTENANCE.md](MAINTENANCE.md) before
   substantial or AI-assisted changes.
2. Open an issue or discussion before making substantial unsolicited changes.
3. Submit changes through a focused pull request.
4. Let repository CI complete before merge.
5. Keep changes easy to review and grounded in current public evidence.

## Content principles

Please avoid adding:

- unsupported claims;
- exaggerated achievements;
- private or sensitive information;
- stale contribution/project status;
- unrelated promotional content;
- decorative widgets that add more noise than information.

AI-assisted contributions are welcome, but the contributor remains responsible
for verifying every public factual claim against current GitHub/project
evidence.

The goal is to maintain an accurate, restrained, and professional technical
profile.
