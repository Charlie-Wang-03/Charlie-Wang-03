# Security Policy

## Reporting a security issue

This repository is a personal profile and documentation repository. If you discover a security issue related to repository contents, please avoid public disclosure before contacting the maintainer.

Please report potential security concerns through GitHub private communication or the contact information listed in the profile README.

## Scope

This policy applies to:

- accidental exposure of sensitive information;
- malicious changes to repository content;
- issues affecting linked resources or maintained configuration files.

This repository does not currently provide production software services.
