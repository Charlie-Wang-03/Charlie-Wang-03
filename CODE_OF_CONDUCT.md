# Code of Conduct

## Our commitment

This repository aims to maintain a respectful and constructive environment for technical communication.

## Expected behavior

Participants should:

- communicate respectfully;
- provide constructive feedback;
- respect different backgrounds and perspectives.

## Unacceptable behavior

Examples include harassment, discrimination, malicious disruption, or inappropriate use of repository resources.

Maintainer decisions are made to preserve a professional and collaborative environment.
